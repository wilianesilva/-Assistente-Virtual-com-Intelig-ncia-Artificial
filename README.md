 # Junior: Educador Financeiro Jovem 💰👦👧

## 📖 Sobre o Projeto
O **Junior** é um assistente virtual divertido e interativo que ensina **finanças para crianças e adolescentes**.  
Ele ajuda jovens a entender conceitos básicos de dinheiro, poupança e planejamento de forma lúdica, usando metáforas, histórias e exemplos do dia a dia.

---

## 🎯 Objetivo
- Ensinar educação financeira desde cedo.  
- Explicar conceitos como gastar, poupar e investir de forma simples.  
- Incentivar hábitos saudáveis com dinheiro.  
- Tornar o aprendizado divertido e interativo.  

---

## 🧩 Funcionalidades
- Conversa com linguagem acessível e amigável.  
- Usa metáforas de jogos, cofrinhos mágicos e super-heróis para explicar finanças.  
- Faz perguntas para envolver o usuário (“Você já guardou moedas em um cofrinho?”).  
- Responde apenas com base na **base de conhecimento** organizada.  
- Diz quando não tem informação suficiente.  

---

## 📚 Base de Conhecimento
A base de conhecimento contém informações simples e práticas, como:  
- O que é dinheiro e como usamos.  
- Diferença entre gastar, poupar e investir.  
- Como organizar a mesada.  
- Importância da reserva de emergência.  
- Noções de juros com exemplos fáceis.  

Exemplo de entrada:
```json
{
  "pergunta": "O que é poupar?",
  "resposta": "Poupar é como juntar moedas em um cofrinho mágico: cada vez que você guarda, ele fica mais forte para te ajudar no futuro!"
}

🖥️ Aplicação
O protótipo pode ser testado em uma aplicação simples:

Chatbot em Python com Streamlit.

Interface web colorida com ícones de moedas e cofrinhos.

Botões de exemplo: “O que é poupar?”, “Como organizar minha mesada?”, “O que é investir?”.

📊 Avaliação
O desempenho do Junior é avaliado com base em:

Clareza das respostas.

Entendimento por parte de crianças e adolescentes.

Feedback dos usuários.

Exemplo de métrica:

Pergunta	Resposta	Entendimento
O que é mesada?	É o dinheiro que os pais dão regularmente para ensinar a criança a administrar seus gastos.	👍 Sim


🎤 Pitch Final
Problema: Crianças e adolescentes não aprendem sobre dinheiro cedo e podem ter dificuldades no futuro.

Solução: Um assistente virtual divertido que explica finanças com histórias e metáforas.

Valor: Ensina hábitos saudáveis desde cedo, preparando jovens para lidar com dinheiro de forma consciente.
